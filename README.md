# 🏛️ AGOGE

App de entrenamiento fisico inspirada en el sistema espartano.

## Estructura

- `/backend` - API Node.js + Express + MongoDB
- `/mobile` - App React Native + Expo

## Instalación

### Backend
```bash
cd backend
npm install
npm run dev
```

### Mobile
```bash
cd mobile
npm install
npx expo start
```
